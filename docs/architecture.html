角色判断机制
• classAdmins 集合：有记录 = 委员，无记录 = parent
• 每次 App 启动调用 getRole CF，结果存入 app.globalData.role
• 页面内通过 app.globalData.role 直接字符串比较，不使用 getter（防止 this 绑定问题）
• 云函数端通过 getCallerAdmin(db, OPENID) 独立验权，前端权限控制仅用于 UI 显示
